# Berglund Studio website

The site for [berglundstudio.com](https://berglundstudio.com). It is a single static page (`index.html`) with no build step.

Videos are hosted on Vimeo. Each video frame has a `data-vimeo` ID; on the live site the page loads the Vimeo still and plays the video in place.

Hosting: Cloudflare Pages, deployed automatically from the `main` branch.
